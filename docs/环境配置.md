## 路径与运行

- 本地 `/Users/yu/Data/Video2Door/code`；服务器 `ssh pro5000`、`/data/zyf/video2door`。
- 私有环境 `/data/zyf/video2door/.repro/envs/b1z1-blackwell`。
- 独立Conda训练环境 `/data/zyf/video2door/.repro/envs/door-dp-train`：Python3.10、PyTorch2.7.1+cu128、torchvision0.22.1+cu128、LeRobot0.3.3、diffusers0.35.1、huggingface-hub0.35.3、NumPy1.26.4；由 `run_tools/activate_train.sh` 激活，禁用user-site与继承的PYTHONPATH。

- 使用 `high-level/float_ik/learning/run_tools/launch.py` 和 `bounded.py` 激活、采样与记账。

在服务器Bash中，选择符合条件的物理卡后：

```bash
export VIDEO2DOOR_GPU=0
source /data/zyf/video2door/.repro/blackwell/activate.sh
python -m pip check
```

激活脚本按UUID同时映射CUDA/Vulkan到逻辑设备0，设置库路径和线程。Gym进程先导入isaacgym再导入torch。

## 环境适配依据

旧Gym绑定要求Python<3.9，官方旧PyTorch wheel不含sm_120。因此本环境保留Python3.8，使用私有CUDA12.8编译PyTorch2.3.1。运行激活包含Gym/PyTorch共享库处理及Vulkan设备选择层。

环境恢复文件和构建来源保留在 `.repro/blackwell/`：activate.sh、install_runtime.sh、build_torch.sh、pytorch-sm120.patch、torch-wheel.sha256、Vulkan过滤层及版本导出。源码、缓存和依赖环境此次未清理。
