# pro5000运行环境

本地仓库：/Users/yu/Data/Video2Door/code
服务器：ssh pro5000，仓库 /data/zyf/video2door

## 两套项目Conda环境

| 用途 | Prefix | 主要依赖 |
|---|---|---|
| 仿真、专家与闭环推理 | .repro/envs/b1z1-blackwell | Python3.8.20、Isaac Gym、定制Torch2.3.1+sm120/CUDA12.8、NumPy1.23.5、diffusers0.24 |
| LeRobot转换与训练 | .repro/envs/door-dp-train | Python3.10、Torch2.7.1+cu128、torchvision0.22.1、LeRobot0.3.3、diffusers0.35.1、NumPy1.26.4 |

服务器为8×RTX PRO5000 72GB。任务使用单GPU、nice10、数学/PhysX两线程。统一启动器 learning/run_tools/launch.py 会采样空闲GPU并设置环境；训练命令加 --environment train。

手动激活（服务器Bash，GPU编号按实际空闲卡选择）：

```bash
export VIDEO2DOOR_GPU=0
source /data/zyf/video2door/.repro/blackwell/activate.sh
# 或训练环境：
source /data/zyf/video2door/high-level/float_ik/learning/run_tools/activate_train.sh
```

Gym激活脚本按UUID对齐CUDA/Vulkan到逻辑设备0，并设置私有库路径。Gym进程先导入isaacgym，再导入torch。训练环境禁用user-site和继承的PYTHONPATH。
