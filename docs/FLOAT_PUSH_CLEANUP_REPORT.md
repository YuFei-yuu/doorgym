## 保留与适配

原仓库 DP 网络、全身 DP 源码、浮动专家与 IK 工具、机器人/门资产、运行环境均保留。活动学习接口只支持 `float_push_ee_world_v1`，拒绝旧格式；当前 11D 动作、39D 状态及末端 IK 执行/优化设置保持不变。

- `rollout.py` 继续记录动作执行前观测、IK 前末端命令、动作后状态、IK 关节目标、实际关节及视频。
- `run_tools/bounded.py`、`test_budget.py` 从旧目录原样迁移；新增通用资源检查入口 `launch.py`。当前短程驱动通过显式计划传入预算、种子和步数，不继承已删实验的预算或固定种子。

- `offline_eval.py` 支持指定 checkpoint、设备、25/100 推理步、回合数和窗口数；报告末端位置与四元数几何误差，数值统计使用 float64。
