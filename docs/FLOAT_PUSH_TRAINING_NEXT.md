2. 若能保持原物理和策略配置恢复，冻结 15000/25000 及选模记录，只补齐 90 个未启动测试。已启动异常不重跑替换。
3. 若必须改变物理配置，另建评估版本，不与原部分测试直接拼接。
4. 新训练另立 run_id、明确预算与步数上限。原实验虽有剩余时间，优化步数已经达到上限，不能继续从 21000 或 25000 增加更新。

新的配置选择可使用验证种子 4100–4109；最终测试可预留 6000–6029，启动前核对是否已被其他实验使用。旧 3000、4000、5000 系列只作历史诊断或原冻结实验的剩余评估，不再作为新方法的未见测试。

## 新训练的授权与兼容要求

新训练需要用户明确给出额外 GPU 预算、优化步数上限和实验变量；不得把旧文档的 6 小时当作每次重新获得的额度。建议先设有界的单因素对照，按完整验证决定是否继续。

保留 `float_push_joint_v1`、25 步推理和原主成功判据作为基准。manifest 改变时，当前严格 `train.py --resume` 不能直接恢复；必须明确归一化、权重、AdamW 与 RNG 的初始化方式，对照组采用相同规则。窗口或结构改变也不能冒充完整 checkpoint 恢复。

继续要求每 250 步离线验证、每 500 步不可覆盖保存、每 2000 步完整闭环验证；连续三个完整验证点主成功率和平均最终有向门角均无提高则早停，门角容差 0.001°。loss、reach 或限幅改善不取消早停。独立测试只在选模冻结后启动。
