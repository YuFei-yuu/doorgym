## 数据与训练来源

- 起始提交 `9fdeae89613e0597603c605a0f5171723efedca0`，原专家未修改；原脚本三次同配置复测成功，末态约 89.98025°/0.55 m。这是重复性验证，不是泛化测试。
- 门 `99650089960001`、缩放 1.2、60 Hz。初态随机 x±0.05 m、y±0.03 m、yaw±2°；无门参数随机化、无低层步态。
- 采集种子 1000–1019，20 次均成功；按回合预先拆分 14 训练/4 验证/2 留出，成功筛选在分配后。总 57000 样本，分为 39900/11400/5700；窗口不跨回合，统计量只用训练集。
- 原数据 `depth_m` 已有限替换并裁剪到 0–2 m，不是原始深度；缺显式末步后状态。后续记录器增加 `gym_depth_m` 和 `next_state`，`recording-audit/` 单独验证，不替换历史数据或加入训练集。
- 复用原 DoorDiffusionPolicy，关节动作 schema `float_push_joint_v1`，状态 38D、动作 10D、双相机 mask/depth。详细契约统一见 [学习接口](../high-level/float_ik/learning/README.md)。模型不接收专家阶段、时间进度或门 GT，不调用专家 IK。
- 窗口 4/16/4；DDPM 训练 100/推理 25、squaredcos、epsilon、`clip_sample=False`；标准差下限 0.01。AdamW lr=1e-4、weight_decay=0.01、batch=16、梯度裁剪=1、训练种子 42。每 250 步离线验证、500 步保存，额外保留 0/100；实际验证 100→500→2000→5000 完整恢复。
- 首条训练 MSE 1.249941、末条 0.018670、末次验证 0.020601。缓存推理与完整前向最大动作差 0；离线动作误差下降不等于闭环成功。

## 指标口径与诊断证据

| 指标 | 实际定义及单位 |
| --- | --- |
| 原 open_80deg 兼容字段 | 实际 abs(angle)≥20°，不是 80° |
| 原 passed_door 兼容字段 | 上述 20° 条件加 door_x-base_x>0.7 m |
| 本轮主成功 | 已解锁、最终 signed angle≥80°、尾端净距离≥0.52 m；0.52=0.55−0.03 原验证容差 |
| reach / grasp | 分别 0.08/0.12 m 阈值连续 10 步；grasp 另需命令闭合>0.65、实际闭合>0.35。事件按 episode 锁存，独立于原 RL curriculum |
| signed_open_ratio | 复用浮动专家的 abs(q-closed)/关节范围并裁剪 [0,1]；这个兼容名字的实现并非带符号，方向另由 signed_angle_deg 判定 |
| handle_open_ratio | (q-lower)/(upper-lower)，解锁阈值 40/45；原始角度另以度记录 |
| EE / FK 误差 | 实际 EE 到把手距离；关节目标经 FK 得到的目标距离和跟踪误差，单位 m。FK 指标为新增，不冒充原 Cartesian ee_goal 字段 |
| phase | 分别报告 reach、grasp、解锁、开门、最终成功；诊断结果不控制动作 |
| action | 原始/执行动作、逐通道限幅、L2 与差分；混合单位 L2 只作诊断，逐通道轨迹优先 |
| loss / lr / elapsed | 原 DP 噪声预测 MSE、AdamW 学习率、累计训练循环秒数；不等于奖励或任务成功 |

reach/grasp 为锁存事件，不能证明持续接触；尾端投影不检查横向门洞容纳或足接触。未训练 seed 2000 曾瞬时到 90.31°，但未解锁且后来闭合，说明最大角度不能证明成功。输入视觉使用 Gym segmentation 辅助，不能外推真实视觉/新门。

21/21 工程检查通过，涵盖同步、回放、同种子 reset、坐标、禁止专家、阈值、数据隔离及视频解码。源指标与公式见 [metric_sources.json](/Users/yu/Data/Video2Door/reproduction/pro5000/float-push-training/results/tools/metric_sources.json)。逐通道离线误差见 `offline_action_diagnostics.json`；首次偏离摘要见 [早期失败 JSON](FLOAT_PUSH_EARLY_FAILURE_ANALYSIS.json)。
