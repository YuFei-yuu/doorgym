# 浮动底座末端动作：短程 DP 验证

实验：`20261012-ee-short-refined`。接口 `float_push_ee_world_v1`，从随机初始化训练 **2000 步**，固定使用最后模型，没有根据视频或闭环结果选模。代码起点为已推送的 `e32bf75`，本轮专家修正和执行工具另随报告提交。

## 专家质量先行

原专家直接转为末端标签后，存在阶段切换跳变与不可达目标：名义回合目标单步跳变最大约 45.5 cm，末端误差最大约 45.2 cm。第一次只在世界目标冻结时暂停底座，仍出现 29.3 cm 的目标跳变、29.1 cm 的跟踪误差，因此没有进入数据采集或训练；记录保留在 `20261012-195314-ee-short`。

最终专家保留原轨迹规划和 IK/伺服，做两项标签及时序修正：世界接触目标冻结时暂停底座，到原收臂阶段继续通过；在 IK 前限制参考位置每步最多 6 mm、期望目标在实测末端附近 6 cm 内，姿态每步最多 0.035 rad。限步与物理执行使最终跟踪误差不保证严格小于 6 cm。**原始训练/验证配置中，这些规则仅用于生成专家标签，模型执行没有专家规划、门状态辅助或同样的目标平滑器。原始模型闭环失败后，另设通用执行限幅对照；两种配置严格分开记录。** 标签始终是 IK 前末端指令，不用求解后关节 FK 冒充标签。

| 名义专家指标 | 修正后 |
|---|---:|
| 末端位置误差均值 | 2.286 cm |
| 末端位置误差 P95 / 最大 | 5.972 / 6.181 cm |
| IK 关节目标 FK 与实测末端误差 P95 | 5.144 cm |
| 姿态跟踪误差 P95 | 23.99° |
| 目标单步位移最大 | 6.000 mm |

该精度适用于本次短程诊断，并非高精度接触控制已经解决。数据筛选门槛在采集前固定：任务/reach/grasp 通过，2850 步完整，坐标/FK/前后帧契约正确；位置误差 P95 ≤8 cm、最大 ≤15 cm，目标单步 ≤8 cm，伺服位置误差 P95 ≤8 cm、姿态误差 P95 ≤0.6 rad。门槛并不证明无碰撞或持续稳定抓取。

## 数据与训练

预分配训练种子 8100–8115、离线验证 8200–8203；随机化初始 x ±5 cm、y ±3 cm、yaw ±2°。采集前检查未与既有运行种子冲突。共启动 20 条，合格训练 16 条、离线验证 3 条；被筛除种子：[8201]。保留所有尝试，质量筛选不跨回合重分配集合。原 10D 数据没有混入。

11D 动作/39D 状态；原 DP 网络源码不变，双相机四通道视觉；观测/预测/执行窗口 4/16/4，DDPM 训练 100 步、推理 25 步。AdamW lr=1e-4、weight decay=0.01，batch=16，梯度裁剪=1。归一化只用合格训练回合，保存步数 0/500/1000/1500/2000。5 项 CPU 契约测试通过。

2000 步完整完成，梯度和 loss 均有限。固定离线验证噪声 MSE 从第 250 步的 0.135268 变为第 2000 步的 0.059302。该 loss 不是推门成功率。

复用原 `offline_eval.py`，在两条合格离线验证演示的 20 个专家观测窗口上诊断。位置向量 RMSE（各 xyz 通道 RMSE 的平方和开方）由未训练的 24.56 m、500 步的 1.014 m 降至 2000 步的 **0.221 m**；2000 步 xyz 分量分别为 0.216 / 0.041 / 0.019 m。因此在尚未产生闭环状态偏移时，预测误差就已明显大于专家参考步进尺度。该小样本诊断不作为重新选模依据。

补充 CPU 单窗口核验：同一 11D 模型、噪声与 25 步采样下，缓存推理与原始完整 forward 的输出最大差为 0；证据为 `inference_equivalence_cpu.json`。这排除了该窗口中的缓存实现差异，不代表所有设备与观测都经过穷举核验。

## 原始模型闭环失败与执行限幅对照

原定闭环验证种子为 8500/8501/8502。原始直接执行模型在 seed 8500 完成 368 步（6.133 秒）后发生 PhysX GPU narrowphase CUDA 700，随后观测非有限。该组为 **1 已启动、0 完整完成、1 异常，8501/8502 未启动**；失败保留，不以追加对照替换。首个目标与初始末端相差 0.401 m，第 12 帧目标世界位置范数已超过 10 m，第 80 帧超过 1e6 m，最大约 2.08e36 m。已完成转移的状态/动作元素仍有限，但 float32 误差指标有 160 行溢出。世界目标增长先于 CUDA 报错；精确的 CUDA 故障触发原因尚未确定。

作为故障诊断，冻结同一 2000 步 checkpoint，新增 `ee_reference_limited_v1` 执行配置：IK 前用相同纯数学参考限制处理模型输出，只访问原始指令、上一执行指令和实测末端，不访问门 GT、专家阶段或轨迹规划器。专家也通过相同执行配置。**这是看到失败之后增加的执行对照，不是原始策略通过验证，也不是独立泛化测试。** 没有追加优化更新或挑选其他 checkpoint。

对照保留三个预定种子，六条轨迹均完整 2850 步、47.5 秒；每对初始状态和策略图像逐项相同。模型无专家阶段，禁用专家调用检查通过。


| 种子 | 专家成功 | 限幅模型数值成功 | 模型最终门角 | 模型 reach / grasp / 解锁 |
|---|---|---|---:|---|
| 8500 | True | True | 89.975° | False / False / True |
| 8501 | True | False | -0.000° | False / False / False |
| 8502 | True | False | -0.000° | False / False / False |

通用限幅对照中，专家数值成功 3/3，模型数值成功 1/3。门角/尾端距离通过不等于稳定抓把、正确推门或专家轨迹复现，需同时查看 reach/grasp 与视频。不能把这一后加的控制配置与原始模型成绩混合，也不能与旧关节模型不同数据/训练步数的成绩作因果比较。

| 种子 | 专家 / 模型目标跳变 P95 (mm/步) | 专家 / 模型实际末端位移 P95 (mm/步) | 专家 / 模型位置误差 P95 (cm) |
|---|---:|---:|---:|

位移统计按原始 60 Hz 计算；变化大包含有意运动与碰撞响应，不能单凭一个数等同于抖动。逐时刻图、轨迹与同步视频用于联合判读。

**本轮模型尚不合格。** 三个回合均无 reach/grasp，最终底座远离门；8500 的数值成功也不是专家式抓把推门。额外限幅器只限制世界系参考每步 6 mm（0.36 m/s），底座仍允许 0.6 m/s；底座运动会让参考追不上实际末端，两个顺序投影不能同时保证限速和 6 cm 跟踪邻域。实测模型跟踪误差 P95 已达 7.91–9.09 m，不能把该对照当作可部署的执行器修复。它未成为默认控制配置。

## 下一步

1. 先统一底座与末端参考约束：考虑底座运动补偿、可达性及跟踪误差超限时的底座减速；在 IK/PhysX 调用前检查数值范围和求解结果。用固定模型单独验证执行器，不能把门状态或专家阶段加入模型执行路径。
2. 先降低专家观测下约 22 cm 的末端预测误差，再检查最初几十步的闭环状态与上一指令反馈；离线拟合不足和反馈放大都有证据，尚不能归因于单一因素。不要直接把延长训练当作已验证的解决办法。
3. 后续另立数据/执行版本与预算，重做同配置专家/模型对比。主数值判据保留用于历史可比，同时独立报告稳定接触、轨迹跟踪与底座偏离；8500–8502 已用于诊断，不再称未见测试集。
