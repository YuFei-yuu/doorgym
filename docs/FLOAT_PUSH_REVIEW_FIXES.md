## 训练/推理契约接入

新增共享模块`high-level/dp/action_contract.py`。训练入口显式选择`--action_contract forward_v3`，对应版本`door_action_minmax_continuous_quat_v3`。默认`legacy`保留旧入口语义；缺少版本字段的旧checkpoint仍按`door_action_zscore_v1`读取，不允许把旧模型改按新统计解释。

- 动作使用训练集min/max映射到[-1,1]，状态保持z-score；常量动作通道归一化为0并准确还原。
- 每回合首帧四元数的绝对值最大分量取正，随后按与上一帧的内积连续化；仅改变符号，物理姿态不变。状态与动作分别连续化，推理状态采用相同规则。
- 新训练窗口包含回合第0帧及前15帧预测中心，历史不足时重复本回合首帧，不跨回合补齐。
- 状态统计使用训练窗口覆盖的唯一输入帧，动作统计使用实际监督帧；当前90回合为113550个窗口/状态统计帧、116340个动作监督帧。
- 继续逐帧读取LeRobot，只额外保存回合边界和±1符号等索引元数据，不缓存图像、状态或动作帧。
- checkpoint保存版本、补齐规则、四元数规则及完整DDPM配置；新控制器要求epsilon预测和归一化±1裁剪，未知/不完整契约拒绝加载。
- 训练W&B可显式使用`--wandb --wandb_mode offline`，不依赖激活脚本默认disabled配置。

归一化、起始窗口和四元数规则属于同一个新数据契约，不能把首轮仅作静态测试的min/max v2候选与新v3混用。v3需要随机初始化的新模型；本次接入验收时尚未训练，随后已完成文首所述小数据验证。
