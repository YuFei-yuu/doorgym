# 第六轮：动态接触衔接

基于冻结0e42611，独立版本保留开门/穿越/停车/转向/部署和最终收臂/R11。仅接近→推关门槛、切换参考与接触统计变化。

连续≥0.30 s的实际有载末端接触、实际门速度<−0.002 rad/s、累计实际闭门≥0.003 rad、跟踪≤8 mm/0.01 rad后允许切换；沿用8 s部署参考完成条件及16 s接近超时。无接触、单帧接触、位姿失配、不动或反向开门均不放行。没有把最终静止阈值放宽。

切换保存实测门角、q、工具姿态与上一关节命令/变化速度。两秒内从随实际门运动输运的实测工具姿态平滑接至原推关参考；关节命令从上一指令及其变化速度连续衔接，仍限0.7 rad/s。无门角重置、门角写入或辅助力。

CPU检查只读取第五轮retry2冻结实测接近段与切换后2 s反馈，不是物理回放或完整新候选。报告保留反事实指令、正常及六种负例。原0.45 m跟进、70→35°回正、锁存与最终要求不变。本轮仅1次原始名义初态物理回合、最多240 s，失败不自动补跑。
