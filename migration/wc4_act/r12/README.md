# 完整任务 ACT 首轮基线 R12

本轮单 seed1000，从随机初始化ACT（仅ResNet18 ImageNet默认预训练）训练30,000次更新，使用R11全部72条159,529帧。无旧任务权重。010000/020000各固定8回合62300–62307；030000固定64回合62200–62263。每回合最多180秒，总计80次调用，不重试。

入口 `launch.sh prepare <idle-gpu>` 仅冻结配置与初态，不建场景。`launch.sh train <idle-gpu>` 持有项目共享UUID锁完成唯一训练及三个评测时点。原作者优化器循环不改；外围检查每次loss与梯度有限、有效合同、optimizer实际步数、checkpoint、W&B和资源。中期评测为子进程，核对训练RNG不变，不加载或写回训练状态。

策略输入仅单时刻float32 Joint9与原双masked depth。首次输入在物理初态t=0，以后在t=0.04、0.08…采样；每动作保持两个50Hz子步，25步后队列自然补充。初始前两维为0，后续为上一条25Hz实际应用底盘指令。策略输出、物理限幅后的动作、限幅delta、原始图像哈希及源时间均入日志。只用实际actor物理DOF范围，禁用旧IK软限位与夹爪锁存；不做专家补偿。限幅不更改训练数据。

门锁只观察门的实测角和角速度：真实解锁并观察到离开关闭带后，回到≤1°且≤1°/s连续至少0.5秒，锁存最新实测角。锁本身无机器人运动接口、不读取phase或规划。初始锁保持初始实测角；解锁区间不写角；门铰链effort必须始终为0。把手弹簧沿用R7冻结物理。

R11 `criteria.score`独立重算；运行时终态沿用R11无phase函数。自动通过只作为待原片/源码联合审查候选。普通失败计入分母，不替换。每时点保存最早测量通过候选及最早失败的原始整体RGB，原片全解码、25fps及完整时长检查；未选临时RGB在保存SHA与receipt后删除。成功最终需独立检查实际末端推关和释放。缺类注明，不补跑。

新代码全部位于本目录，历史专家/模型/数据不改。prepare冻结全部72个唯一初态/相机tuple并与R8/R9集合查重。所有数值计算、测试、导出、仿真均在pro5000既有项目环境。
