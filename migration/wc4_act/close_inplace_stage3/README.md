独立证据目录：服务器 `.repro/reviews/wc4-close-inplace-stage3-20261027`；本地 `reproduction/wc4-act/wc4-close-inplace-stage3-20261027/FINAL`。

- `local_deploy.py`：局部预接触退距及实体面定位；首次3个退距没有可选悬停姿态，随后显式测试1cm/0两点，检查一条局部关节部署弧线。
- `local_margin.py`：失败接近邻域的8个高度/朝向/退距端点；没有合格组合，没有生成其完整路线。
- `config.json` / `run_candidate.py`：唯一完整候选。独占创建`single`目录，已存在即拒绝，不自动重试。候选执行提交`bacd694`。

- `review.py`：按阶段与具体子基元定位所有重叠，核对原实体采样点，生成停车曲线、关键姿态、接触部位、干涉图和分项报告。

接近门使用原8mm/0.03rad阈值及低速、远侧、外部/自几何检查；未满足时不能进入推关。该门通过不等于真实接触或全段安全。预设门运动与理想受限跟踪都标为合成，禁止当作完整任务成功或训练数据。
