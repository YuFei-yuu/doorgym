# 第五轮：单回合真实执行

以 7beae30 为基线。独立 runtime 保留原开门、物理、R11 TaskMonitor、锁写入规则、Joint9 执行及 25 Hz 原始记录器；新增阶段名只扩展记录元数据。不存在策略或旧模型加载。

首次全身通过后，原世界末端目标及实时 Gym IK 继续工作，仅将到同一 base_traverse 的底盘时间重参数化为第三轮五次多项式。停住后从实测末端向 +y 撤离 0.14 m、收臂，再原地转向270°。第四轮两个关节路标只是目标；到达和静止检查使用实测 q。部署采用完整 SO(3) 姿态；接近完成要求实测位置≤8 mm、姿态≤0.01 rad、关节速度≤0.05 rad/s。

推关目标领先实际门角最多0.8°，2秒平滑加入；绕法向13.5°至80°时15.5°，后续保持。实际门角70→35°期间原地旋转至0°，35°后沿前向跟进，名义0.45 m计划不优化。实际关节作IK初值；关节指令速率≤0.7 rad/s，底盘前向≤0.04 m/s，转动≤0.2 rad/s（独立原地转向≤0.6）。关闭阶段若12秒无5 mrad进展或2秒严重跟踪偏差停止。部署/收臂等阶段有有界等待，不跳过门槛。沿用原锁监视器，锁住实测角而非写零。锁后末端后撤0.12 m，实测脱离后收臂并恢复原朝向。

0.45 m是计划范围，实际门运动、阶段门槛或240秒/异常停止可导致未完成，不能宣称足额平移、完整成功或物理推关。少量静态检查不是全程净空证明。沿用HOME源交叠和预期接触亚毫米间隔仅作诊断。

执行：`bash migration/wc4_act/close_inplace_stage5/launch.sh RUN GPU_INDEX`。准备仅一次；scene-claim在创建场景前以独占方式写入。共享UUID flock、GPU空闲、10GiB保存估计和40GiB保留空间守卫。仅整体RGB录像；原始双路uint8 depth与原始记录时钟持续保存。
