# 第七轮：固定慢速推关参考

保持第六轮动态切换及前段。切换后仅内部时钟与冻结交接姿态生成参考：3秒到参考70°、10秒回正至参考35°、13秒沿前向跟进0.45 m至参考0°，总26秒。后两段采用平滑速度起落与匀速中段，保持0.2 rad/s及0.04 m/s底盘限速；非突然跳转的角度状态。参考作者trajectory_targets中step/duration插值方式；参考角只是路径参数，不是门状态。

起点承接实测姿态及上一关节命令/速度，2秒渐入。关闭时实测门角和接触不驱动路径、不驱动进度，取消门无进展停机；脱离接触允许。保留对固定机械臂目标的严重执行跟踪异常保护，不能将门角偏离参考误记为机械臂跟踪失败。到达固定终点后持续停留，只有参考完成且原TaskMonitor实际角度/速度/0.5秒保持条件通过才能合法锁存；不写零、不辅助施力。

终点至少0.5秒停留且实测机械臂/底盘已停稳、合法锁存后，沿用4秒释放、7秒收臂、12秒恢复朝向及2秒最终R11保持。名义动态切换约67.30秒，参考终点约93.30秒，若实际条件及时满足，最终约117.8秒；实际不满足则等到120秒停止。最终判据不放宽。

仅1个原始名义初态物理回合，最多6000步/120秒，无补跑、参数扫描或平移减量。检查只核验一条时间参考的连续性/限速以及实测门角/接触输入不改变推关目标，不作为物理完成证据。
